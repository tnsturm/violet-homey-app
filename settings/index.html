Violet — Quick Start

This app talks to your Violet or BADU Blue pool controller over your local network — no cloud account needed. Here is the short version of what the settings do.

Getting started

Add a Pool device and enter the controller’s host or IP. Try violet.local first; if that does not resolve on your network, use the IP address instead. A static IP is recommended so Homey does not lose the controller after a router reboot.

Reading values needs no credentials at all. The write username and password are optional: you only need them to enable control (write), and as a fallback if your controller restricts config reads.

Water temperature sensor

Auto picks the sensor whose Violet name looks like the pool. With several sensors and no clear name, choose yours manually — the temperature tiles are labelled with your own Violet names, so you can tell which sensor is which.

This is also the temperature the LSI calculation uses.

Feature groups

Every group — eco mode, heater, solar, backwash, cover, light, water refill, overflow tank, water level, PV surplus and measurement inputs — offers Auto, Always show or Hide. Dosing offers Auto or Hide only.

Auto follows the hardware your controller actually reports, so you get no empty tiles. Always show forces the tile. Hide removes it — and that breaks any Flow that uses it.

Water chemistry (LSI)

Off by default. Switch on Compute LSI and enter calcium hardness, total alkalinity and cyanuric acid from your test kit or PoolLab. Balanced water sits between -0.3 and +0.5, with 0 as the ideal.

The advisor turns the LSI into concrete dosing suggestions and a startup plan for freshly filled water. It needs LSI enabled, plus the pool volume if you want amounts in grams or millilitres. It only advises — it never doses anything itself.

Control (write access)

Off by default. Once enabled, control tiles appear and Flow actions can command the controller, using the write username and password from the device settings.

The controller’s local API is plain HTTP on your LAN, so the write password travels unencrypted inside your network. Switching the pump ON or OFF from the tile reverts to Auto after the default override duration.

Diagnostics and alarms

Show advanced diagnostics adds tiles for CPU, memory, uptime, firmware and controller errors.

On the alarm listener port this app receives the Violet’s own NOTIFY pushes. That channel has neither encryption nor authentication, so keep it on your LAN and never forward the port to the internet. The hint on the setting itself explains how to point the controller at it.
